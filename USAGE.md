## About UNIT23 AI

A simple, reliable API service for open-source AI models. Pay less, get more.

## What We Offer

- **Low Cost** — Up to 90% cheaper than official APIs
- **Prepaid** — Add credits when you need them, no surprises
- **Transparent** — See exactly what you spend
- **Secure** — Your data is protected
- **Flexible** — Use OpenAI, Claude, or any format you prefer

## Getting Started

1. Create an account at `https://oneapi.unit23api.com`
2. Add credits (Stripe top-up; **minimum $5 USD**)
3. Get your API key and start building

System email (verification, notices) is sent via Resend from **`oneapi@unit23.xyz`**.
